## 第二步：用 QuickTime 分段录屏

1. 打开 **QuickTime Player**（Spotlight 搜 `QuickTime`，或 `/Applications/QuickTime Player`）。
2. 菜单 **文件 → 新建屏幕录制**。
3. 点红色录制按钮旁的下拉，确认"麦克风"选"无"（我们不要声音）。
4. 点录制按钮后，**拖选浏览器窗口区域**（建议把浏览器窗口拉到合适大小再录），松手即开始。
5. 录完点右上角菜单栏的**停止**按钮（●）。
6. **文件 → 存储**，保存到：
   ```
   /Users/vickywu/WorkBuddy/2026-07-26-16-50-27/compliance-triangle/demo/raw/step1.mov
   ```
   第二段存 `step2.mov`，依此类推。

> 建议 1080p。每段录前把要展示的内容先准备好（比如先打开某个分页签），录的时候直接操作，不用来回切。

## 第三步：分别录这 5 段

每段下方的「字幕」是 AI 事后自动加的，**你不用念**。你只需把对应画面录下来、做对应操作。

### step1.mov · 开场（约 20 秒）
- **画面**：浏览器演示页总览（可并排露一点终端，显示服务在跑）。
- **操作**：无，静置展示页面即可。
- **自动字幕**：`律师·税务师·专利代理师 → AI 法律产品`

### step2.mov · 启动 + 看演示场景（约 30 秒）
- **画面**：滚动演示页，点开一个演示场景的分页签，展示彩色卡片。
- **操作**：
  1. 向下滚动，展示"5 个演示场景"区。
  2. 点开其中一个场景（如"股权回购"）的分页签，露出引注核验卡片。
- **自动字幕**：`本地零依赖启动 | 内置 5 个含幻觉演示场景`

### step3.mov · 核心演示：粘贴 AI 回答并校验（约 60 秒 · 最关键）
- **画面**：聚焦"实时校验"文本框。
- **操作**：
  1. 清空文本框，把下面这段**提前复制到剪贴板**，录时直接 `Cmd+V` 粘贴：
     ```
     我们做个股权回购：依据《公司法》第142条，股份有限公司可以收购本公司股份；
     但要注意《旧公司法》第16条规定的决议程序。另外《个人所得税法》第999条
     对股权转让所得有特别规定。
     ```
  2. 点 **「运行校验」**。
  3. 等结果出来，停留几秒让观众看清 🟢 / 🔴 徽章。
- **自动字幕**：`粘贴 LLM 回答 → 运行校验 → 逐条核对官方法条库`

### step4.mov · 调模型生成并校验（约 30 秒 · 可选）
> 前提：你本地设过某国产模型 key（如 `DEEPSEEK_API_KEY`）。**没设也能录**——页面会自动显示"仅粘贴校验"提示，录那段提示即可（照样体现产品能力）。

- **画面**：同页面，模型选择下拉 + 场景输入框。
- **操作**：
  - 若已设 key：选模型 → 填场景 → 点「调用模型并校验」→ 等结果。
  - 若未设 key：滚动到该区域，录下"未检测到 API key，仅粘贴校验"的提示文字。
- **自动字幕**：`输入场景 → 调国产模型生成 → 自动校验`

### step5.mov · 收尾（约 20 秒）
- **画面**：回到演示页总览，或切到 GitHub 仓库页 `github.com/vickywu97/compliance-triangle`。
- **操作**：无，静置展示。
- **自动字幕**：`地基 2327 条核验法条 · 32 测试全绿 · 开源`
