# 合规三角 · 演示录屏脚本（2–3 分钟）

> 用途：照着这份脚本录一段 2–3 分钟的演示视频，放进 GitHub README / 作品集 / 面试附件。
> 目标观众：AI 法律产品 / 合规岗的 hiring manager。核心要让他们 30 秒内看懂——
> **"这个产品能拦住 AI 编造的法条引注，并用 🟢🟡🔴 标出来"**。
> 录制建议：1080p，区域录制浏览器 + 终端即可，无需露脸。语速放慢，关键结论重复一遍。

---

## 0:00–0:20 开场（20 秒）

**画面**：终端 + 浏览器并排。
**旁白**：
> 我是 Vicky，律师、税务师、专利代理师，现在转做 AI 法律产品。
> 我做的这个工具叫「合规三角」——它解决一个很具体但很危险的问题：
> **AI 在引用法条时，会编造条文、引用已废止的法律、张冠李戴。**
> 而合规三角能给 AI 生成的每一条法条引注，盖上 🟢🟡🔴 的章。

**操作**：无。保持两张窗口并排即可。

---

## 0:20–0:50 启动 + 看演示场景（30 秒）

**画面**：终端启动服务，浏览器打开页面。
**操作**：
```bash
cd compliance-triangle
python -m compliance_triangle.web
# 打开 http://127.0.0.1:8000
```
**旁白**：
> 它完全离线、零依赖，只用 Python 标准库。本地起一个服务，打开就是这个仪表盘。
> 页面内置了 5 个演示场景——这些场景里的 AI 回答**故意埋了幻觉**：虚构的条号、已废止的旧公司法、
> 引用了根本不存在的第 999 条。

**操作**：滚动页面，点到一个演示场景的分页签，展示彩色卡片。

---

## 0:50–1:50 核心演示：粘贴你自己的 AI 回答（60 秒 · 最关键）

**画面**：聚焦「实时校验」文本框。
**操作**：清空文本框，粘贴下面这段（提前复制到剪贴板）：

```
我们做个股权回购：依据《公司法》第142条，股份有限公司可以收购本公司股份；
但要注意《旧公司法》第16条规定的决议程序。另外《个人所得税法》第999条
对股权转让所得有特别规定。
```

**旁白**（边粘贴边说）：
> 这才是重点——你把你自己任何一个 LLM 生成的合规分析粘进来，
> 只要它带了《法律》第X条这种引注，点「运行校验」，系统就用同一套引擎逐条核对官方法条库。
> 我们跑一下。

**操作**：点「运行校验」。
**旁白**（看结果出来后）：
> 看结果：
> - 《公司法》第142条——🟢 通过，条文真实、在有效期内；
> - 《旧公司法》第16条——🔴 未通过，这是**已废止的法律**，2024 新公司法施行后不能再引用；
> - 《个人所得税法》第999条——🔴 未通过，**这条根本不存在**。
>
> 一句话：AI 犯的三种典型错误——引对、引废止法、引虚构条号——一眼被标出来。
> 这就是我把"量化幻觉"的基准，变成"实时拦截"的产品。

---

## 1:50–2:30 （可选）真正调模型生成并校验

> 前提：你本地设了某个国产模型 API key（如 `DEEPSEEK_API_KEY`）。没设也能录，页面会自动降级成"仅粘贴校验"并提示。

**画面**：同页面，模型选择下拉 + 场景输入框。
**操作**：选一个模型，填场景，点「调用模型并校验」。
**旁白**：
> 如果设了模型 key，它还能反过来——你给个业务场景，它调国产模型生成分析，
> 然后**自动把生成结果送进同一套校验层**。生成和把关是同一条流水线，不是两个工具。
